# Engagement Manager

This project is a C++17 proof of concept for tracking engagements and assigning resources.

## Build and run

Requires a C++17 compiler and Make. The included Makefile builds the demo and tests.

```sh
make
make test
./build/demo
```

To remove the build files, run `make clean`.

## Current scope

The program runs in one process and keeps data in memory.
